## What is InsightIQ?

InsightIQ is a production-style AI Business Intelligence system that converts
natural language questions into SQL queries, executes them safely, generates
interactive visualizations, and produces executive PDF reports — automatically.

Built for non-technical business users and data teams who need instant insights
without writing a single line of SQL.

## Key Features

| Feature | Description |
|---|---|
| Natural Language to SQL | Ask questions in plain English, get accurate SQL |
| Agentic Self-Healing Loop | Auto-retries failed queries up to 3 times |
| 99.8% Token Optimization | Schema summarization vs raw CSV passing |
| 15+ Auto KPIs | Revenue, orders, customers, segments, regions |
| 10 Interactive Charts | Bar, line, pie, heatmap, US map, and more |
| Smart Chart Picker | AI selects the best visualization automatically |
| Executive PDF Export | One-click professional business report |
| Dataset Profiler | Auto data quality report on upload |
| Query History | Track all session queries with metadata |
| Safety Guardrails | Blocks DROP, DELETE, ALTER, UPDATE operations |
